# 🌿 PlantTech Diagnostics

PlantTech Diagnostics is a Machine Learning and Computer Vision–based project focused on analyzing plant leaf images to diagnose plant health and disease conditions.  
The project explores and compares multiple classical ML models to understand their performance on real-world visual data.

This repository is built as a **learning-oriented yet practical AI/ML system**, demonstrating the full pipeline from image preprocessing to model training and prediction.

---

## 🚀 Project Objective

The goal of this project is to:
- Analyze plant leaf images
- Extract meaningful visual features
- Train and compare multiple ML classifiers
- Predict plant health or disease status
- Understand how different algorithms behave on the same dataset

This project is especially useful for **AI/ML and Computer Vision students** who want hands-on experience beyond theory.

---

## 🧠 Models & Visualizers Used

The project experiments with and compares the following Machine Learning models:

- **Support Vector Machine (SVM)**
- **K-Nearest Neighbors (KNN)**
- **Random Forest Classifier**

These models are used to:
- Visualize decision boundaries
- Compare accuracy and generalization
- Analyze strengths and weaknesses of each approach
- Understand how classical ML performs on image-based data
